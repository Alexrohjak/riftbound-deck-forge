Retired
Restructured 2026-08-03. D-043 — EE is a rules engine with a swappable mouth, and the mouth is Claude Code against exported state. D-044 splits the engine so the track delivers before its hardest half is finished.
S1a is still the largest single component. 21 cards rewrite rules an engine would hardcode, so rules must be data, not code. Build it vertically: one battlefield, 1v1, full fidelity, then widen — and leave room for a priority stack, or S1b becomes a rewrite instead of a deferral.
S6 is what makes EE usable — the role S3 used to hold. It turns “66 cards refute this” into “fragile to cheap Mind interaction — attack when they're tapped out.” The difference is that the prose is Claude's job and only the contract is built.
